# Data Files Description

This document explains the purpose of the files stored under the `data/` directory.

## Directory Overview

```text
data/
|-- raw/
|-- processed/
|-- analysis/
`-- modeling/
```

- `raw/` stores downloaded source data. These files are raw inputs and can be regenerated by download scripts.
- `processed/` stores cleaned and feature-engineered datasets used by analysis and modeling scripts.
- `analysis/` stores statistical analysis outputs in CSV/JSON format.
- `modeling/` stores machine learning and deep learning model outputs.

## `data/raw/`

### `data/raw/jolpica/`

Raw JSON files downloaded from the Jolpica-F1 API.

Generated by:

```powershell
python download_jolpica_f1_data.py
```

Validated by:

```powershell
python validate_jolpica_f1_data.py
```

Main contents:

- `download_summary.json`: summary metadata for the Jolpica-F1 download run.
- `2019/` to `2026/`: season-level API files.
- `races.json`: race calendar and circuit information.
- `results.json`: race result records.
- `qualifying.json`: qualifying result records.
- `driverStandings.json`: driver standings.
- `constructorStandings.json`: constructor standings.
- `drivers.json`: driver metadata.
- `constructors.json`: constructor metadata.

These files are source data and are ignored by Git because they can be downloaded again.

## `data/processed/`

### `f1_model_dataset.csv`

Modern driver-race modeling table built from Jolpica-F1 raw JSON.

Each row represents one driver in one race.

Generated by:

```powershell
python build_f1_model_dataset.py
```

Used by:

- `build_f1_features.py`
- `build_f1_extended_features.py`

### `f1_features.csv`

Feature-engineered modern dataset based on `f1_model_dataset.csv`.

It adds pre-race standings, recent form, history counts, and data-quality flags.

Generated by:

```powershell
python build_f1_features.py
```

Used by:

- `analyze_f1_basic_stats.py`
- `visualize_f1_analysis.py`
- model scripts when the extended feature table is unavailable

### `f1_2026_schedule.csv`

Full 2026 race schedule with a flag showing whether each race already has result data.

Generated by:

```powershell
python build_f1_model_dataset.py
```

Used by:

- `analyze_f1_basic_stats.py`
- later 2026 prediction work

### `build_summary.json`

Metadata summary for `f1_model_dataset.csv` and `f1_2026_schedule.csv`.

It records generation time, output paths, fields, row counts, and 2026 completed rounds.

### `feature_summary.json`

Metadata summary for `f1_features.csv`.

It records feature fields, row counts by year, missing qualifying rows, and grid-zero rows.

### `f1_model_dataset_extended.csv`

Extended modeling table combining:

- SQLite historical records from 2003 to 2017
- Jolpica-F1 modern records from 2019 to 2026

Generated by:

```powershell
python build_f1_extended_features.py
```

This file increases the modeling sample size for machine learning experiments.

### `f1_features_extended.csv`

Extended feature-engineered table based on `f1_model_dataset_extended.csv`.

This is the preferred input for current machine learning and deep learning scripts.

Used by:

- `train_f1_podium_model.py`
- `train_f1_podium_deep_model.py`
- `train_f1_points_model.py`
- `simulate_f1_season_uncertainty.py`
- `predict_f1_2026_championship.py`

### `extended_feature_summary.json`

Metadata summary for the extended feature dataset.

It records:

- historical source database
- modern source file
- historical year range
- total row count
- rows by year
- explanation for using 2003 as the historical starting point

## `data/analysis/`

This folder stores statistical analysis outputs.

Generated by:

```powershell
python analyze_f1_basic_stats.py
python analyze_f1_historical_sqlite.py
python analyze_f1_circuit_archetypes.py
```

Interactive query helper:

```powershell
python query_f1_data.py
```

`query_f1_data.py` loads all available structured project data into an in-memory SQLite database. The query console automatically includes:

- All CSV and JSON files under `data/`.
- Local Kaggle CSV folders, including `formula-1-fantasy-2021/` and `formula1-data-1950-2022/`, when they exist.
- Every raw table from local SQLite databases under `formula-1-race-data-sqlite/`, when they exist.

Figure and video output manifests are not loaded, because the query tool is limited to data sources and generated data tables.

When `formula-1-race-data-sqlite/Formula1.sqlite` is available, it also exposes historical joined convenience tables:

- `historical_races`: race calendar and circuit metadata from 1950 to 2018.
- `historical_results`: driver-race results from 1950 to 2017.

The helper also creates a queryable `data_catalog` table with loaded table names, row counts, source types, source paths, and columns. It does not create new data files; it is used to inspect records with SQL-style commands during exploratory analysis.

### Modern analysis files

These files mainly use complete modern seasons from 2019 to 2025. The 2026 season is handled separately as current-season state data.

- `dataset_overview.csv`: dataset size and entity counts.
- `dataset_overview_by_year.csv`: yearly row, race, driver, constructor, circuit, podium, and top-10 counts.
- `grid_finish_summary.csv`: correlation and rate summary for grid and race results.
- `grid_position_summary.csv`: outcome rates by starting grid position.
- `qualifying_position_summary.csv`: outcome rates by qualifying position.
- `feature_correlation_summary.csv`: Pearson and Spearman correlations between features and target outcomes.
- `driver_summary.csv`: driver-level total points, wins, podiums, top-10s, and average positions.
- `driver_points_by_year.csv`: driver performance by season.
- `constructor_summary.csv`: constructor-level total points, wins, podiums, top-10s, and average positions.
- `constructor_points_by_year.csv`: constructor performance by season.
- `constructor_competitiveness_by_year.csv`: constructor points concentration, HHI, and effective constructor count.
- `pre_race_strength_bins.csv`: podium/top-10 rates by pre-race strength bins.
- `circuit_summary.csv`: circuit-level pole win rate, front-3 podium rate, and position-change statistics.
- `circuit_grid_importance_score.csv`: composite circuit grid-importance score.
- `driver_position_gain_summary.csv`: driver grid-to-finish position gain summary.
- `constructor_position_gain_summary.csv`: constructor grid-to-finish position gain summary.
- `reliability_by_year.csv`: classified, incident, and mechanical/other status rates by year.
- `driver_reliability_summary.csv`: driver reliability summary.
- `constructor_reliability_summary.csv`: constructor reliability summary.
- `teammate_comparison.csv`: teammate comparison by season and constructor.
- `circuit_volatility_index.csv`: circuit volatility score based on position changes and surprise winners.
- `analysis_summary.json`: metadata summary for modern analysis outputs.

### 2026 current-season files

- `current_2026_driver_standings.csv`: current 2026 driver standings from completed races.
- `current_2026_constructor_standings.csv`: current 2026 constructor standings from completed races.
- `completed_2026_results.csv`: completed 2026 race results.
- `remaining_2026_schedule.csv`: remaining 2026 races without completed race results.

### Historical analysis files

These files are generated from `Formula1.sqlite` and are used as historical background.

- `dataset_overview_historical.csv`: historical database coverage and entity counts.
- `races_by_year_historical.csv`: number of races by year.
- `driver_wins_historical.csv`: top historical race-winning drivers.
- `constructor_wins_historical.csv`: top historical race-winning constructors.
- `grid_finish_summary_historical.csv`: historical grid-to-finish summary.
- `grid_position_summary_historical.csv`: historical outcome rates by grid position.
- `analysis_historical_summary.json`: metadata summary for historical analysis outputs.

## `data/modeling/`

This folder stores model evaluation outputs and prediction tables.

Modeling note: raw race `points` are preserved in processed and analysis files for historical statistics. Prediction-stage point targets and point-based pre-race features are normalized from finish position using the current Grand Prix scoring table, excluding Sprint and fastest-lap bonus points.

Generated by:

```powershell
python train_f1_podium_model.py
python train_f1_podium_deep_model.py
python train_f1_points_model.py
python train_f1_finish_bucket_model.py
python score_f1_podium_models.py
python simulate_f1_season_uncertainty.py
python tune_f1_feedback_weight.py
python tune_f1_current_form_boost.py
python backtest_f1_model_scenarios.py
python predict_f1_2026_championship.py
python analyze_f1_circuit_archetypes.py
python select_f1_prediction_scenarios.py
```

### Main modeling and prediction outputs

- `podium_model_metrics.csv`: metrics for logistic regression, random forest, extra trees, calibrated random forest, and histogram gradient boosting.
- `podium_predictions_2025.csv`: predicted podium probability for each 2025 driver-race row.
- `podium_top3_predictions_2025.csv`: top 3 predicted podium candidates per 2025 race.
- `podium_feature_importance.csv`: feature importance for the selected tree-based model.
- `podium_logistic_feature_effects.csv`: logistic regression feature coefficients.
- `podium_rolling_backtest_metrics.csv`: expanding-window backtest results from 2022 to 2025.
- `podium_feature_mode_summary.csv`: average rolling-backtest performance by feature mode and model.
- `podium_completed_2026_probabilities.csv`: model probabilities for completed 2026 races.
- `podium_model_summary.json`: metadata summary for the traditional ML model pipeline.
- `podium_model_composite_scores.csv`: one 0-100 composite score for each ML, advanced ML, and DL model.
- `podium_model_composite_score_summary.json`: metadata summary for the composite scoring method and best model.
- `top10_model_metrics.csv`: classification metrics for Top 10 prediction models, including traditional ML, advanced boosting, MLP, and TabNet classifiers.
- `points_model_metrics.csv`: regression metrics for race-points prediction models, including traditional ML, advanced boosting, MLP, and TabNet regressors.
- `points_predictions_2025.csv`: 2025 Top 10 probability and predicted race points by driver-race row.
- `points_completed_2026_predictions.csv`: Top 10 probability and predicted race points for completed 2026 races.
- `top10_race_level_metrics_2025.csv`: race-level Precision@10, Recall@10, and points capture rate for Top 10 predictions.
- `points_error_by_points_bin_2025.csv`: race-points regression error grouped by actual-points bins.
- `top10_calibration_metrics_2025.csv`: calibration bins for Top 10 probabilities, comparing predicted probability with actual Top 10 rate.
- `points_rule_mapped_predictions_2025.csv`: race-level points predictions after mapping ranked drivers to the official F1 points table.
- `points_rule_mapped_summary_2025.csv`: MAE, RMSE, and total-points comparison between continuous regression points and rule-mapped race points.
- `points_race_level_error_2025.csv`: race-by-race points prediction errors and Top 10 hits for the 2025 test season.
- `top10_points_rolling_backtest_metrics.csv`: rolling backtest metrics for compact Top 10 and points model choices from 2022 to 2025.
- `points_correction_experiment_2025.csv`: experimental points-model correction results for high-score underestimation.
- `model_task_summary.csv`: compact best-model summary across podium, Top 10, and race-points tasks.
- `top10_feature_importance.csv`: feature importance for the best Top 10 model.
- `points_feature_importance.csv`: feature importance for the best race-points model.
- `points_model_summary.json`: metadata summary for Top 10 and race-points prediction models.
- `finish_bucket_model_metrics.csv`: 2025 evaluation metrics for finish-bucket multiclass models.
- `finish_bucket_predictions_2025.csv`: finish-bucket probabilities, predicted bucket, and expected points for 2025 driver-race rows.
- `finish_bucket_race_diagnostics_2025.csv`: race-level winner diagnostics from finish-bucket probability models.
- `finish_bucket_model_summary.json`: metadata summary for the finish-bucket multiclass experiment.
- `top10_calibrated_predictions_2025.csv`: Top 10 probabilities after leave-one-race-out empirical calibration.
- `top10_calibrated_probability_bins_2025.csv`: raw versus calibrated probability bins for 2025.
- `top10_calibrated_probability_summary_2025.csv`: Brier score and expected calibration error before and after calibration.
- `rule_mapped_strategy_predictions_2025.csv`: race-level F1 points assigned by each ranking strategy.
- `rule_mapped_strategy_metrics_2025.csv`: MAE, RMSE, Top 10 precision, Top 3 precision, and winner hit rate for each rule-mapped strategy.
- `season_simulation_driver_standings_2025.csv`: Monte Carlo driver standings backtest with champion, Top 3, and Top 5 probabilities.
- `season_simulation_constructor_standings_2025.csv`: Monte Carlo constructor standings backtest with champion, Top 3, and Top 5 probabilities.
- `season_simulation_summary_2025.csv`: compact driver and constructor championship uncertainty summary.
- `season_simulation_summary_2025.json`: metadata summary for strategy comparison, calibration, and simulation outputs.
- `feedback_weight_tuning_metrics.csv`: 2022-2025 historical backtest details for candidate future-feature feedback weights.
- `feedback_weight_tuning_summary.csv`: aggregated feedback-weight tuning metrics; the selected weight minimizes average combined driver/constructor points MAE.
- `feedback_weight_tuning_summary.json`: metadata summary for feedback-weight tuning, including candidate weights and selected best value.
- `current_form_boost_backtest_metrics.csv`: 2022-2025 backtest details for current-season online training and short-history form-boost configurations.
- `current_form_boost_backtest_summary.csv`: aggregated current-form experiment metrics, including the conservative adoption candidate used by the final 2026 predictor.
- `current_form_boost_backtest_driver_focus.csv`: per-driver diagnostics for active short-history drivers in each current-form backtest.
- `current_form_boost_backtest_summary.json`: metadata summary for the current-form experiment, including best overall configuration and recommended official configuration.
- `season_model_scenario_backtest_metrics.csv`: 2022-2025 season-level rollout details for candidate Top 10 and points-model combinations.
- `season_model_scenario_backtest_summary.csv`: aggregated season-level model-combination backtest metrics, including points MAE, champion hit rates, Top 3 overlap, and winner-concentration diagnostics.
- `season_model_scenario_backtest_summary.json`: metadata summary for the season-level model-combination backtest and its best-ranked diagnostic row.
- `season_prediction_driver_standings_2026.csv`: final 2026 driver championship prediction with current points, projected points intervals, champion probability, Top 3 probability, and Top 5 probability.
- `season_prediction_constructor_standings_2026.csv`: final 2026 constructor championship prediction with current points, projected points intervals, champion probability, Top 3 probability, and Top 5 probability.
- `season_prediction_race_points_2026.csv`: deterministic rule-mapped points prediction for each remaining 2026 race and driver, including the race-level raw predicted-points percentile used for ranking, winner-runner-up score gap, and a race-level winner confidence label for the predicted winner row.
- `season_prediction_summary_2026.csv`: compact 2026 predicted champion summary for drivers and constructors.
- `season_prediction_summary_2026.json`: metadata summary for the final 2026 championship prediction pipeline.
- `season_prediction_model_scenarios_2026.csv`: champion prediction comparison for the primary pre-race scenario, the original metric-ranked sensitivity scenarios, and the season-backtest-derived S4/S5 diagnostic scenarios.
- `season_prediction_model_scenario_diagnostics_2026.csv`: diagnostics for each 2026 model scenario, including deterministic race-winner concentration and champion probability margins.
- `season_prediction_race_signal_diagnostics_2026.csv`: race-by-race winner and runner-up signal diagnostics for each 2026 model scenario, including ranking-score gaps, winner confidence level, raw predicted-points percentile gaps, predicted-points gaps, and calibrated Top 10 probability gaps.
- `season_prediction_top10_calibration_2026.csv`: empirical Top 10 probability calibration table used by each 2026 model scenario.
- `season_prediction_driver_standings_2026_by_model.csv`: driver championship prediction details for each model scenario.
- `season_prediction_constructor_standings_2026_by_model.csv`: constructor championship prediction details for each model scenario.
- `season_prediction_race_points_2026_by_model.csv`: remaining-race deterministic rule-mapped points predictions for each model scenario.

### Circuit archetype diagnostics

- `analysis/circuit_archetypes_2019_2025.csv`: rule-based circuit archetype labels built from grid importance, overtaking, and volatility metrics.
- `analysis/circuit_archetype_summary.json`: metadata summary for the circuit archetype diagnostics.
- `modeling/season_prediction_circuit_archetype_diagnostics_2026.csv`: 2026 model-scenario winner concentration diagnostics grouped by circuit archetype.
- `modeling/season_prediction_scenario_selection_2026.csv`: scenario selection scores combining validation performance, winner diversity, concentration penalties, ranking-gap diagnostics, and circuit-archetype concentration.
- `modeling/season_prediction_scenario_selection_summary_2026.json`: metadata summary for 2026 scenario selection.
